## ⚡ About SmartCine  
**SmartCine** is a **Hybrid Movie Recommendation System** built using **Machine Learning & NLP**.  
It combines **Clustering (K-Means, Hierarchical, DBSCAN)** and **Association Rule Mining (Apriori & FP-Growth)**  
to recommend movies similar in genre, cast, and storyline — all inside a stunning cinematic UI powered by **Streamlit**.
