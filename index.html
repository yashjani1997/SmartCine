// 02 — Intelligence

HYBRID SEARCH LOGIC

🧠 Dataset Movies
ML-Based Cosine Similarity

For movies in the TMDB 5000 dataset, the trained model extracts feature vectors and computes cosine similarity to return the most semantically similar movies.

🌐 New / Unseen Movies
TMDB API + Genre Fallback

For new or unseen movies not in the training set, SmartCine queries the TMDB API in real-time and falls back to genre-based recommendations — solving the cold-start problem.

// 03 — Integration

TMDB API ENDPOINTS

Endpoint Purpose
/movie/{id} Fetch movie details, poster, backdrop, ratings, overview
/movie/{id}/videos Fetch YouTube trailer link for the movie
/trending/movie/week Live trending movies updated weekly
/search/movie?query= Real-time search for any new or unseen movie
